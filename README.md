# generic-xml-writer

A lightweight, generic Java library for writing XML files from any collection of Java objects. Define which fields to include and how to extract their values — the writer handles the rest.

## Features

- **Generic** — works with any Java type `T`
- **Flexible field mapping** — use lambda expressions or method references to extract values
- **Collection support** — fields that return a `Collection` are automatically serialized as XML lists
- **Null handling** — choose between an empty element or an exception when a value extractor returns `null`
- **Optional file comment** — write a comment at the top of the generated XML file
- **Configurable buffer size** — tune the internal write buffer for large datasets
- **Automatic cleanup** — if writing fails, any partially created file is deleted

## Requirements

- Java 17 or higher
- Maven (for building)

## Building

```bash
mvn package
```

## Usage

### 1. Define your data class

```java
public record Person(String name, int age, String email) {}
```

### 2. Create `XmlField` mappings

Each `XmlField` maps an XML tag name to a value extractor function:

```java
XmlField<Person> nameField  = new XmlField<>("name",  Person::name);
XmlField<Person> ageField   = new XmlField<>("age",   Person::age);
XmlField<Person> emailField = new XmlField<>("email", Person::email);
```

### 3. Create an `XmlFileWriter`

```java
XmlFileWriter<Person> writer = new XmlFileWriter<>(nameField, ageField, emailField);
```

### 4. Write the XML file

```java
List<Person> people = List.of(
    new Person("Alice", 30, "alice@example.com"),
    new Person("Bob",   25, "bob@example.com")
);

writer.writeAndCreateXMLFile(
    "/output/directory",   // destination path
    "people",              // file name (without extension)
    "Persons",             // root element name
    people                 // collection of objects to write
);
// Creates /output/directory/people.xml
```

### Generated XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Persons>
    <Person>
        <name>Alice</name>
        <age>30</age>
        <email>alice@example.com</email>
    </Person>
    <Person>
        <name>Bob</name>
        <age>25</age>
        <email>bob@example.com</email>
    </Person>
</Persons>
```

### Advanced: optional comment and custom buffer size

```java
writer.writeAndCreateXMLFile(
    "/output/directory",
    "people",
    "Persons",
    "Generated by generic-xml-writer",  // optional XML comment
    8192,                                // buffer size in bytes (default: 8192)
    people
);
```

This adds a comment at the top of the file, right after the XML declaration:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!--Generated by generic-xml-writer-->
<Persons>
    ...
</Persons>
```

### Collection fields

If a value extractor returns a `Collection`, the library automatically wraps each item in `<item>` tags:

```java
public record Team(String teamName, List<String> members) {}

XmlFileWriter<Team> writer = new XmlFileWriter<>(
    new XmlField<>("teamName", Team::teamName),
    new XmlField<>("members",  Team::members)
);
```

Generated output:

```xml
<Teams>
    <Team>
        <teamName>Dev Team</teamName>
        <members>
            <item>Alice</item>
            <item>Bob</item>
            <item>Charlie</item>
        </members>
    </Team>
</Teams>
```

## API Reference

### `XmlFileWriter<T>`

| Constructor / Method | Description |
|---|---|
| `XmlFileWriter(XmlField<T>... xmlFields)` | Creates a writer with the given field definitions. At least one field is required. |
| `writeAndCreateXMLFile(String destinationPath, String fileName, String rootElementName, Collection<T> elements)` | Writes the XML file with default buffer size (8192 bytes) and no comment. |
| `writeAndCreateXMLFile(String destinationPath, String fileName, String rootElementName, String comment, int bufferSize, Collection<T> elements)` | Writes the XML file with a custom comment and buffer size. |

All parameters must be non-null and non-blank. The elements collection must not be empty. Throws `XMLFileWriterException` on any validation or I/O failure.

### `XmlField<T>`

| Constructor | Description |
|---|---|
| `XmlField(String name, Function<T, Object> valueExtractor)` | Creates a field with `NullBehavior.EMPTY_ELEMENT_VALUE` (default). |
| `XmlField(String name, Function<T, Object> valueExtractor, NullBehavior nullBehavior)` | Creates a field with an explicit null behavior. |

#### `NullBehavior`

| Value | Description |
|---|---|
| `EMPTY_ELEMENT_VALUE` | If the extractor returns `null`, the XML tag is written with no content (e.g. `<name></name>`). This is the default. |
| `THROW_EXCEPTION` | If the extractor returns `null`, an `XMLFileWriterException` is thrown and the file is not created. |

### `XMLFileWriterException`

An unchecked (`RuntimeException`) exception thrown when:
- Required parameters are `null` or blank
- The elements collection is `null` or empty
- The buffer size is less than 1
- An I/O error occurs during file writing
- A `THROW_EXCEPTION` field extractor returns `null`
